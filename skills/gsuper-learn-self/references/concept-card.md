# Concept card (personal)

One file per plan session may hold several cards.

```markdown
# Learning — <plan title>

Source plan: `.agent-workflow/plans/YYYY-MM-DD-<feature>.md`
Date: …

## Card 1 — <concept name>

**Why it showed up here:** tie to Task N / what you actually built (1–2 sentences).

**Core idea:** 3–6 lines. Precise. No filler.

**In this work:** how the shipped steps used it (paths or sample pointer).

**Trap:** what people (incl. agents) get wrong.

**Explain-back:** one question you should answer in your own words (no looking at the card).

## Card 2 — …
```

Max **4 cards** per plan. Merge thin ideas; drop trivia.
