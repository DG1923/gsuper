# specs/ — project documents

Ticket AC is **`plans/`**, not this folder.

Put durable docs here, one file per topic, **plain language**:

| Folder | Use for |
|--------|---------|
| `algorithm/` | How a recipe / algorithm works |
| `srs/` | Software requirements |
| `feature/` | A large product feature |
| `architecture/` | Design of a feature or subsystem |
| `system/` | System structure / system design |

Write or update only when the user asks (**gsuper-write-spec**). Unknown folder names: ask; do not invent.

Dated files `YYYY-MM-DD-<ticket>.md` in this directory root are leftover **ticket** specs. Leave them. New tickets do not add files here.
